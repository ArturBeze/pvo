# Arducam ToF — простой просмотр

Окно tkinter с выбором **Глубина** или **Confidence**. Фильтрации, восстановления
и управления сервоприводами нет. Изображение выводится через OpenCV и Pillow.
Все файлы программы находятся в этой папке; исходные примеры проекта не изменены.

## Запуск из корня проекта

```bash
python -m pip install -r tof_viewer/requirements.txt
python tof_viewer/app.py
```

На Raspberry Pi нужны работающий драйвер и модуль `ArducamDepthCamera`, как для
вашего `clue/time-of-flight.py`. Используется тот же API и CSI-индекс 0.
SDK камеры устанавливается отдельно. Нужен Python с tkinter и графический сеанс.
Для системного Python Raspberry Pi OS: `sudo apt install python3-tk`.
Для Python из pyenv поддержка Tk должна быть включена при сборке.

В PyCharm укажите `tof_viewer/app.py` как Script path и выберите интерпретатор
с установленными зависимостями и SDK.

Без камеры:

```bash
python tof_viewer/app.py --demo
```

Дополнительные параметры запуска: `--range 2000` (по умолчанию 4000 мм)
и `--index 0` (индекс камеры SDK).

Глубина отображается цветом в диапазоне 0…выбранный максимум, некорректные
значения — чёрным. Порог confidence к глубине не применяется.
Confidence отображается в сером с фиксированной шкалой 0…255: больше — светлее.
Значения вне шкалы обрезаются только для отображения; исходные массивы не меняются.
Фактический диапазон confidence показан в статусе.
Выберите нужное изображение в выпадающем списке слева.

Камера читается в отдельном потоке, чтобы окно оставалось отзывчивым.
При закрытии окна поток останавливается и камера освобождается.
