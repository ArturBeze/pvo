# Камера ToF — OpenCV

Независимый скрипт, без tkinter и зависимости от tof_workspace.
Запускайте на Raspberry Pi в графическом рабочем столе, используя Python,
в котором уже работает пример clue/time-of-flight.py. Нужны numpy,
opencv-python с поддержкой окон (не headless), ArducamDepthCamera и драйвер камеры.
Остальные программы захвата этой камеры перед запуском закройте.

Из корня PVO:

```sh
python tof_opencv/view_camera.py
python tof_opencv/view_camera.py --confidence 200 --min 300 --max 1200
```

Пороги включительные: сохраняются точки с confidence >= 200 и глубиной
300 <= depth <= 1200 мм. Нули, NaN/Inf и отсечённые точки показаны чёрным.
Цветовая шкала фиксирована от min (синий) до max (красный).
Аргументы принимают дробные значения. Настройки меняются при перезапуске.

Дополнительные параметры: `--index 0` — индекс камеры в SDK;
`--range 4000` — аппаратный диапазон (2000 или 4000 мм).
Он отличается от программного отсечения min/max.

Выход — Q в латинской раскладке, Esc или закрытие окна.
Скрипт ничего не записывает и не изменяет исходные данные.

Для небольших кадров используется один цикл: получение → векторная обработка →
отображение. Нет очереди кадров на стороне приложения и обмена массивами между
процессами. Буфер SDK освобождается сразу после обработки. Ожидание кадра
ограничено 100 мс, после 5 секунд без кадров выводится ошибка. Если нативный SDK
зависнет и проигнорирует тайм-аут, окно может перестать отвечать.
Реальный FPS печатается раз в две секунды; скорость на устройстве зависит от SDK,
настроек камеры и нагрузки Raspberry Pi. Измерений на реальной камере здесь нет.
